# VCU Workshop 02 — Between the lines

1회차와 독립된 두 번째 워크숍 웹앱입니다. 네 장면 보드, 원형 댓글 핀, 닉네임, 작성자 수정·삭제, 한/영 전환, 지속 아카이브, 진행자 전용 로컬 VAD 분석과 감정 지도를 포함합니다. 마지막 장면 번호는 2-2로 정리했습니다.

## 지금 로컬에서 보기

이 폴더에서 `npm ci` 후 `npm run dev`를 실행하고 http://localhost:5174 를 엽니다. 현재 작업 환경에서는 상위 폴더의 설치된 패키지로도 실행됩니다. 진행자 비밀번호는 Git에서 제외된 `.env`의 `VCU_ADMIN_PASSWORD`로 설정합니다. 미설정 시 개발 기본값은 `local-preview-only`입니다. 다른 장치에서는 같은 네트워크의 이 컴퓨터 IP와 5174 포트를 사용합니다.

데이터는 이 폴더 `.data/`에 보관합니다. 재실행해도 남으며 Git에 포함되지 않습니다. 로컬 데이터와 배포 데이터는 별도입니다.

## GitHub → Netlify

이 폴더만 새 GitHub 저장소로 올리거나 기존 저장소에서 Netlify Base directory를 `workshop-02`로 지정합니다. 1회차 Netlify 프로젝트와 별개의 새 프로젝트를 만드세요.

- Build command: `npm run build`
- Publish directory: `dist`
- Functions: `netlify/functions` (netlify.toml에 지정)
- 서버 환경변수 `VCU_ADMIN_PASSWORD`: 실제 진행자 비밀번호
- 서버 환경변수 `VCU_AUTH_SECRET`: 임의의 32자 이상 비밀 문자열
- 비밀 문자열 생성 예: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
- 두 변수에 VITE_ 접두사를 붙이지 마세요. 환경변수 설정 후 배포합니다.

방 생성 없이 같은 URL을 사용합니다. Netlify Blobs의 `vcu-session-02`에 댓글별 객체와 분석 작업을 저장합니다. 일반 재배포로 데이터가 초기화되지 않습니다. 사이트 삭제 전 JSON 백업을 받으세요. 활성 화면은 약 3초마다 갱신되며 숨겨진 탭은 조회를 멈춥니다. WebSocket 방식은 아닙니다. 함수·저장소 요청은 Netlify 사용량에 포함됩니다.

## 현장 진행

1. 참가자가 닉네임을 정하고 장면을 읽습니다.
2. 점선 보드의 원하는 위치 또는 '감상 남기기'를 누릅니다.
3. 감정 태그나 감상 중 하나 이상을 입력합니다. 한국어·영어 모두 가능합니다.
4. 원형 핀을 눌러 전문을 봅니다. 핀이 겹쳐도 '모두 보기'로 모든 글에 접근할 수 있습니다.
5. 자신의 글은 같은 브라우저에서 수정·삭제합니다. 닉네임은 인증 비밀번호가 아니며, 서버가 별도의 서명된 작성자 토큰을 확인합니다. 브라우저 데이터를 지우거나 1년이 지나면 진행자에게 수정·삭제를 요청하세요. 진행자는 모든 글을 관리할 수 있습니다.
6. 아래 로컬 워커를 실행하고 웹에서 진행자 로그인 → VAD 분석 시작을 누릅니다.
7. 감정 지도 페이지에서 결과를 함께 봅니다. 지도 점을 눌러 원문을 읽고 장면별 필터를 적용할 수 있습니다.
8. 진행자 메뉴에서 JSON을 내려받아 별도로 보관합니다.

## 로컬 VAD 모델

Python 3.10+ 표준 라이브러리만 사용합니다. Ollama가 localhost:11434에서 켜져 있어야 합니다. 이미 설치한 `qwen3:4b-instruct`를 사용합니다. 없으면 Ollama 공식 설치 후 `ollama pull qwen3:4b-instruct`로 준비합니다.

```powershell
python scripts/vad_worker.py --site https://YOUR-SECOND-SITE.netlify.app
# 로컬 페이지에 연결
python scripts/vad_worker.py --site http://localhost:5174
```

비밀번호는 실행 후 숨김 입력합니다. 워커는 진행자 컴퓨터에서 사이트로 나가는 요청만 사용하므로 포트포워딩이 필요 없습니다. 컴퓨터와 Ollama, 워커를 켜두세요. Ollama가 켜져 있지 않으면 분석은 실패로 표시됩니다. 가짜 점수나 클라우드 AI로 대체하지 않습니다. 작업 중에는 30초 간격으로 연결을 갱신하고, 10분간 끊긴 작업은 다음 워커가 다시 가져옵니다. 진행자 토큰은 7일 후 만료되어 재시작이 필요합니다.

VAD는 **0~1** 척도입니다. V는 불쾌→쾌, A는 차분함→각성, D는 무력감→주도감입니다. 여기서는 별도 VAD 전용 학습 모델이 아닌 **로컬 Qwen의 지시문 기반 VAD 추정**을 사용합니다. 연구용으로 검증된 점수나 심리 진단으로 간주하지 마세요. 문화·언어에 따른 해석은 워크숍에서 함께 검토할 자료입니다. 분석 입력은 참가자의 태그와 감상이며, 영화 인물의 감정과 구분하도록 지시합니다.

분석 요청 시점의 댓글 버전을 고정합니다. 이후 새 글은 재분석해야 포함됩니다. 수정·삭제한 글의 이전 점수는 공개 지도에서 제외합니다. 이전 분석 작업의 원문 스냅샷은 서버에 보존되고 공개 API에서는 제공하지 않습니다. 삭제는 보드에서 제거하며 이전 분석 스냅샷까지 완전히 지우는 기능은 아닙니다.

## 더블클릭으로 시작

`Start Workshop.cmd`를 더블클릭하면 웹사이트, Ollama, 분석 워커를 순서대로 확인하고 꺼진 항목을 실행한 뒤 브라우저를 엽니다. 비밀번호는 `.env`에서 읽으므로 매번 입력하지 않습니다. 이미 실행 중인 항목은 중복 실행하지 않습니다. 성공 후 실행 창은 닫히고 서비스는 백그라운드에서 유지됩니다. 컴퓨터를 재시작한 뒤에는 다시 더블클릭하세요. 오류가 나면 창이 남으며 상세 로그는 `.data/launcher-*.log`에 기록됩니다. Node.js, Python, Ollama와 Qwen 모델은 사전에 설치되어 있어야 합니다. 현재 컴퓨터에는 준비되어 있습니다.

## 모바일 참여와 접속 표시

첫 접속에는 닉네임 설정을 먼저 완료합니다. 랜덤 닉네임을 바꾸거나 직접 입력할 수 있습니다. 닉네임과 작성자 토큰은 같은 브라우저에 저장합니다. 작성자 토큰에서 만든 고유 색상은 댓글 핀, 상세 보기, 목록, 감정 지도에 공통으로 사용합니다. 기존 댓글에도 작성자 기준 색상을 적용합니다. 색상은 감정 점수가 아닙니다.

상단 접속 인원은 닉네임을 정하고 화면을 보고 있는 브라우저 참가자 수입니다. 같은 브라우저의 여러 탭은 중복 집계하지 않습니다. 활성 탭은 15초마다 연결을 알리고 화면 목록은 약 3초마다 갱신합니다. 숨겨진 화면이나 닫힌 탭은 제외되며, 갑작스러운 연결 종료는 최대 45초 후 제외됩니다. 같은 사람이 다른 기기에서 접속하면 별도 참가자로 집계합니다.
